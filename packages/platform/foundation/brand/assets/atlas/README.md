# Atlas app mark

`app-icon.svg` uses the canonical Athyper master mark for Atlas. It is an independently addressed Atlas asset, copied from `master-marks/athyper-favicon.svg`; it does not reference any plane's app icon.

The brand sync script publishes it at `/brand/atlas/app-icon.svg` in NEON, MESH and Studio. `AtlasBrandIcon` in platform icons renders it as a current-color mask for light, dark and inverse surfaces. Adjacent text/button labels provide its accessible name by default; standalone usage supplies `title`.

Changing this asset later changes Atlas branding without changing plane icons or browser favicons.
