These synthetic fixtures belong to shared publication contract tests. They are
not deployable metadata, approved releases, or replacements for removed business
applications. `review-package.json` exercises comments, attachments, presentation
members and an unsigned review envelope. `projection-package.json` exercises
registered storage sources, derived values and canonical form identity. Services
compile the same fixtures; negative tests mutate them to verify rejection.

Hashes in the input review fixture are illustrative parsing inputs. The compiler
tests remove them and calculate real canonical artifact/release hashes.
