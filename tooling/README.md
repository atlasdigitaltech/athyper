# Tooling

Repository engineering support lives here:

- `config/` contains shared compiler and repository-tool configuration.
- `scripts/` contains repository automation, verification, release, and policy commands.
- `tools/` contains lower-level developer tools and generators.
- `performance/` contains load tests, budgets, baselines, datasets, and qualification assets.

Runtime deployment assets remain in `deploy/`, and repository-wide tests remain in
`tests/`.
