## Scope and interpretation

This is a conservative **static source dependency inventory**, not a browser/server execution-coverage report. It follows the record page, parent layouts, route boundaries, proxy, relay, relevant auth endpoints, and selected record backend service entry points identified from host composition. It recursively resolves imports, re-exports, literal dynamic imports and type imports using TypeScript module resolution.

- Shared barrels and modules containing multiple screens expand the list. Inclusion does not mean a file executes on this record, ships in its browser bundle, or is unique to this page. Tree shaking and conditional rendering can remove code.
- Type-only dependencies are included. `files.csv` shows incoming edge kinds; `dependency-edges.csv` identifies every traced importer and its source line. A mixed import can carry both types and runtime values.
- HTTP calls and dependency injection are not ordinary imports. Selected record backend implementations are explicit trace seeds. The seed list is recorded in `trace-details.json`; the full host registration module is deliberately not traversed because it registers unrelated applications too.
- All record sections, conditional providers and operations reachable through those services are included conservatively. Optional shell tools such as Inbox, Notifications and Atlas have additional backend registrations that were not exhaustively traced here.
- No authenticated browser session or live server coverage was captured. The local source tree was not compared with the deployed build. Therefore this is not a claim that all 531 files execute for the supplied URL.
- Excludes third-party `node_modules`, tests, stories, fixtures, generated Next.js build output, CSS, SQL and JSON. Compiled metadata/release JSON controls which sections and presentation settings appear; it is outside the requested extensions.
- The requested `Server/packages/` directory is actually lowercase `server/packages/` in this repository.
