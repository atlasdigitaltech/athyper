# Country entity route TypeScript file inventory

Snapshot: 2026-09-28. 655 .ts/.tsx files in the route adapters and scoped implementation packages listed below.

## Route mapping

All three Neon URLs use apps/neon/app/(shell)/app/entity/[entityCode]/[[...segments]]/page.tsx.

- /app/entity/country: shared EntityListRuntime when no catalog-specific route matches.
- /app/entity/country/manage: the same shared EntityListRuntime; manage is treated as no record ID.
- /app/entity/country/<UUID>: shared EntityDetailRuntime through EntityReadRuntime when no specialized record adapter matches.
- section=overview and tab=overview select detail navigation state; they are not separate page files.

## Scope and limitations

This is a **package-scope implementation inventory**, not a claim that every listed file executes on each URL or was newly developed for Country. Complete entity/runtime, collaboration, records, metadata, authoring and publication package contents are included to avoid omitting supporting code and tests; they may contain adjacent functionality and historical fixtures. App adapters include equivalents in Neon, Mesh and Studio. Host composition and publication/provisioning tools are included separately.

Git status is only a current-worktree observation, not authorship or development history. M means modified; ?? means untracked; tracked unchanged means no reported working-tree change. Existing untracked/modified files may predate this task. The inventory does not restore or modify BP metadata.

Only .ts and .tsx are listed. Country authoring JSON, profile JSON, CSS, SQL, .mjs tooling, generated output, node_modules, and transitive framework/design-system/auth infrastructure are excluded. The inventory is therefore exhaustive within the stated scopes, not a whole-program transitive dependency closure. Publication/authoring files build and deploy the runtime metadata; they are not all request-time page dependencies.
