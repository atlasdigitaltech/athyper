# Junction retirement

Source junctions were used during the package regrouping transition. They are retired from all
canonical source paths. Windows junctions are not portable to Linux, containers, or production
artifacts and are therefore prohibited under `apps`, `packages`, `server`, and `tooling`.

The only permitted links are dependency links generated by pnpm beneath `node_modules` after
installation. Verify the rule with:

```bash
pnpm policy:no-source-junctions
```

When retiring a legacy path, first migrate imports and tests, compare and back up divergent source,
remove the obsolete workspace exclusion only when safe, then delete the old path. The canonical
physical paths work unchanged on Windows and Linux; no link recreation step is required.
