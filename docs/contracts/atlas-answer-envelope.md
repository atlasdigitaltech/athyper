# Atlas answer presentation (BP-AI-05)

The browser-neutral `@athyper/server-contract-ai/answer` entry point defines the version-1 answer envelope and strict reference validator. Generated presentation contains a kind, summary, optional explanation, finding/evidence IDs and an optional next-action ID. It cannot supply routes, commands, facts, statuses or counts. Validation rejects unknown properties, oversized prose, duplicate/unknown references, and findings whose supporting evidence is omitted. A next action must also be present in the caller's current authorized capability/proposal set; an owner reference alone does not enable execution.

The current prose streaming path assembles an explanation envelope from completed text and server citation events. It does not ask the model to invent JSON or infer structured claims from prose. `insight.cited` transports validated disclosure projections from the registered BP brief, readiness and eligibility tools. Owner results supply coverage, observation times, freshness, findings and facts. Invalid envelopes display a conservative retry message. An interrupted stream cannot become a completed answer.

Dock and fullscreen share the same renderer. Fullscreen is bounded to the viewport and history collapses on narrow screens. Sources are readable links to expandable evidence details next to the answer, including revision/observation information when supplied. These are local evidence links, not reconstructed record routes. Source groups are labeled per answer. Source activation opens the details, preserves keyboard focus on its summary and reveals the source within the scroll region. Markdown supports paragraphs, bold text, inline code and bullet lists; HTML, images, model URLs and other syntax remain inert text. Streaming prose remains plain text. Existing governed action previews retain their separate explicit confirmation and owner validation path.

Starter buttons fill the editable composer without issuing a request. Their questions distinguish filtered lists, selected records, saved records with unsaved edits, historical records and cases. Workspace entry focuses the composer; Escape closes a closable dock and unmount restores the previous focus target when still connected. The conversation has a named polite log region and visible keyboard focus styles.

Replay remains subject to BP-AI-03 server lineage authorization. New tool-result blocks persist server-owned source coordinates; bounded authorized history carries deduplicated source metadata separately from model content. New follow-up answers retain that provenance in hashed message content. Replay joins text chunks exactly, preserving the original streaming whitespace. Replayed tool results containing insight projections use the same validating assessment renderer. Legacy text-only history has no reconstructed citation or action authority. New structured model selection and registered navigation adapters can use the envelope validator when those owner capabilities are enabled; no additional mutation capability is introduced here.
