## Root cause and implementation

The isolated BP runtime is present, but its separately published dependencies are absent. The authenticated create endpoint fails at onboarding schema resolution before it can reach the governed case store. Review & Approval fails because `business_partner_request` has no active descriptor.

1. Prepared onboarding 3.1.2 from the recorded 3.1.1 source. Only semantic version and source-contract bindings change. The old bindings were placeholders. The candidate binds to hashes captured from the exact isolated image's request, eligibility, Mesh profile and matching modules. Source provenance, deterministic compilation, request-schema selection and routed workflow selection pass locally. These fixture results are not deployment evidence.
2. Added native-to-runtime compilation for the registered BP request summary. It resolves actual catalog permission IDs, preserves independent organization ownership, and emits the runtime descriptor expected by the Records parser. Its six fields are `id`, `case_code`, `operation_code`, `status`, `created_at`, and `updated_at`. Only discover/read operations exist. The required organization coordinate derives from the registered current-snapshot relationship resolver. Arbitrary fields, direct writes, incompatible catalogs and unimplemented target-runtime declarations are rejected.
3. Wired the conversion into the native publication worker. The consumer descriptor receives its own content hash; native descriptor and contract hashes remain manifest provenance. The worker signs the actual canonical contract bytes through its configured signer. This implementation has not run against an authenticated published child revision yet.
4. Closed a direct-read hole: document collections now retrieve record IDs through the same constrained list query. Missing resolvers and missing/denied coordinates fail closed even if the principal has a broad read grant. SQL still constrains tenant, BP subject, current snapshot and authorized organization.
5. Switched the command qualification runner to the isolated UI session client, avoiding dependency on the unrelated shared source API boot failure.
